# Indian Liver Patient Dataset

A concise exploratory data analysis project using the Indian Liver Patient Dataset (ILPD).

## Files

- `Indian Liver Patient Dataset.ipynb` — notebook with data checks, visualizations, takeaways, and limitations.
- `Indian Liver Patient Dataset (Raw).csv` — dataset used by the notebook.

## Run

Open the notebook in Jupyter and run the cells from top to bottom. It uses `pandas`, `matplotlib`, and `seaborn`. The data-loading cell supports starting Jupyter from either this folder or the repository root.

The notebook corrects the source CSV's misaligned field labels before analysis. Its findings are descriptive, and the dataset should not be used for medical decisions.
